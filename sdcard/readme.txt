folder naming at core and sound sd card
---------------------------------------

folder 10 : core configuration and data

folders 1n : gadget configuration and data (11=dice, 12=story, 13=music, ...)

	config.json : gadget configuration
	data : json files and other data files
	images : image files (.raw and other formats)
	website : config.json configuration of website (optional)

folders n0 ... n9 : extra folders for gadget n 
	dice has no extra folders
	2n : folder for story n
	3n : folder for music category n
